# Manuscript Grid · 稿纸格子

Zotero PDF 阅读器插件：在 PDF 上插入**作文稿纸式**的文字框。每行固定 25 格，一字一格，往下拉按整行增减，像答题卷一样往格子里填字。

> 适用于 Zotero 7 / 8 / 9（在 9.0.6 上开发和测试）。

## 功能

- **一键生成**：阅读器右上角出现「格」按钮，点击后在当前页生成 25 列 × 4 行的格子。
- **宽度锁定**：每行固定 25 格，宽度不可改变。
- **按整行伸缩**：拖动框的下边缘，松手后吸附为整行，可增可减，行数不限。
- **一字一格**：数字、字母、半角标点、空格在输入时自动转为全角，每个字符占一格。
- **块状光标**：当前输入位置高亮一整格，类似命令行光标。
- **等比缩放**：工具栏 `A+` / `A-` 逐档放大缩小，或右键格子选「格子大小」。共 5 档（100% / 86% / 71% / 57% / 43%），新建的格子沿用上次选的大小。
- **Tab 键**：在格子里按 Tab 空两格（两个全角空格）。
- **转换已有批注**：在左侧批注列表右键一个文字批注，选「转为稿纸格子 (25列)」。
- **原生批注**：格子本质是 Zotero 自带的文字批注，随 Zotero 同步，可在批注列表中查看和删除。

## 安装

1. 到 [Releases](https://github.com/y-0768/zotero-manuscript-grid/releases) 下载 `manuscript-grid.xpi`。
2. Zotero 菜单「工具 → 插件」，点右上角齿轮，选「Install Plugin From File」。
3. 选择下载的 `.xpi` 文件，按提示重启 Zotero。

## 使用

1. 用 Zotero 打开任意 PDF，等待几秒，右上角出现「格」按钮。
2. 翻到想写的页面，点「格」，在当前页可见区域的左上角生成一个 25 × 4 的格子。
3. 点进格子直接输入。满 25 字自动换行，回车手动换行。
4. 需要更多行：拖动框下边缘往下拉，松手后自动对齐整行。要减少行数则往上拖。
5. 把已有的普通文字批注变成格子：在批注列表右键它，选「转为稿纸格子 (25列)」。

## 原理

- 格子是一个带标签（`gridbox:text`、`gridbox:rows:N`）的文字批注，行数记录在标签里。
- 插件向阅读器页面注入样式：内边距清零、行高固定为 1.25 倍字号、强制每行 25 字，并用背景渐变画出格线。
- 监听批注修改，把宽度锁回 25 格，并把高度吸附为整行。

## 已知限制

- **格线不会写入导出的 PDF**。格线是阅读器里的显示样式，导出或用其他阅读器打开时只有文字，没有格子。
- **蓝色选中框可能跳动**。它画在整页批注画布上，与高亮等批注共用，无法单独隐藏，输入时可能随 Zotero 的自动缩框而变化。
- **文字会变成全角**。输入的数字、字母会存为全角字符（如 `123` 存为 `１２３`），以保证一字一格。
- **评论首尾含零宽字符**。为防止阅读器去掉行首/行尾的空格，保存时会在评论首尾加零宽字符，不影响显示。
- **两位数字不能共用一格**，这与真实稿纸的写法不同。
- **依赖阅读器内部结构**。Zotero 大版本升级后可能需要适配。
- 格子大小只有 5 档，暂不支持自定义列数。

## 常见问题

**看不到「格」按钮？** 等待几秒让阅读器加载完，仍没有就重启 Zotero。

**拉不长或行数不对？** 往下拉超过半行再松手；松手后稍等片刻让插件吸附。

**怎么删除格子？** 在左侧批注列表中选中对应的文字批注，按 Delete。

**调试日志？** 「帮助 → 调试输出记录」中查看带 `[GridBox]` 的行。
