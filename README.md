# Manuscript Grid · 稿纸格子 (Zotero 7/8/9)

在 Zotero PDF 阅读器里插入**作文稿纸式**文本框：每行固定 25 格，一字一格，向下拖拽按整行增减。

- 阅读器右上角「格」按钮：在当前页生成 25 列 × 4 行的格子（本质是原生文字批注，随 Zotero 同步）
- 宽度锁定 25 格，拖拽高度松手后吸附为整行
- 数字/字母/半角标点自动转全角，保证一字一格
- 块状光标高亮当前格，类似终端
- 右键批注列表中的文字批注 →「转为稿纸格子 (25列)」可转换已有文字批注

## 限制
- 格线是阅读器内的显示样式，**不会写入导出的 PDF**（文字会保留）
- 选中时的蓝色边框来自阅读器画布，输入时可能跳动
- 依赖阅读器内部结构，Zotero 大版本升级后可能需要适配

## 安装
从 [Releases](../../releases) 下载 `manuscript-grid.xpi`，Zotero →「工具 → 插件」→ 齿轮 → Install Plugin From File。

## 构建
`python build.py` 生成 xpi。
